# Solo 11 - Fantasy Cricket App

This project is a Dream11 clone using Android for the frontend and MongoDB Atlas for the database.

## Prerequisites
- Android Studio
- MongoDB Atlas Account
- PHP Backend Server (e.g., XAMPP or a cloud host)

## Setup
1. Create a MongoDB Atlas cluster.
2. Get your connection string.
3. Update `admin-api/login.php` with your connection string.
4. Host the `admin-api` folder on your server.
5. Update `app/src/main/java/com/solo11come/utils/Constants.java` with your server URL.

## Features
- Splash Screen
- Login with Phone
- Home Screen with Match Listings
- Match Details (Coming Soon)
- Team Selection (Coming Soon)
